# 面试准备 — 总览与 SOP

> **用途**：拿到面试通知 / 接到 HR 电话时的入口文档。明确流程、案例索引、调用路径。
> **最后更新**：2026-05-22

---

## 1. 接到 HR 首轮电话时

→ 立即翻 [[HR首轮电话脚本]]
→ 通话后 10 分钟内把信息记入 `投递跟踪.md`

## 2. 拿到正式面试通知时（SOP）

```
通知到手
  ↓
Step 1：建公司面试档案
  路径：面试准备/面试复盘/<公司>_<日期>.md
  ↓
Step 2：公司背调（30-60min）
  - 业务模式、近期动态、组织架构、面试官 LinkedIn
  - 把信息记到档案
  ↓
Step 3：JD 重读 + 案例匹配
  - 重读 JD 关键词
  - 从 [[案例库]] 挑 3-5 个最契合的案例 ID
  - 在档案里写："本场预计被问 → 调用案例 ID"

  **快速筛选方法论**：
  1. 扫描 JD 高频信号词（≥2次出现）：
     - 领导力类 → CASE-BPCE-01 / CASE-NCR-03 / CASE-HERTZ-02
     - 端到端交付 → CASE-BPCE-02 / CASE-NCR-01 / CASE-BPCE-06
     - 数据驱动 → CASE-BPCE-05 / CASE-BPCE-04 / CASE-NCR-03
     - 变革管理 → CASE-NCR-01 / CASE-WUXI-01 / CASE-HERTZ-02
     - 冲突管理 → CASE-WUXI-01 / CASE-CONFLICT-01
     - BA/需求 → CASE-BPCE-06 / CASE-NCR-01 / CASE-BPCE-05
     - Portfolio/多项目 → CASE-NCR-03 / CASE-BPCE-01
  2. 识别岗位类型（参考 `skill-modules/CN/00_模块索引.md`）：
     - 转型 PM → 优先 BPCE-01/02/06 + NCR-01
     - PMO/Senior PM → 优先 NCR-03 + BPCE-01 + NCR-01
     - 商业 IT PM/BA → 优先 BPCE-05/06 + NCR-01
     - BRM/IT Director → 优先 BPCE-01 + NCR-03 + BPCE-05
  3. 自检：每个案例查看"💡 自检"段，确认适用性
  4. 备选：多准备 1-2 个案例，防现场冷场
  ↓
Step 4：高频题准备
  - "介绍自己 / 为什么离开 BPCE / 期望薪资" 翻 [[HR首轮电话脚本]]
  - 行为题准备：基于 Step 3 选的案例口述一遍
  ↓
Step 5：反问问题准备
  - 至少准备 5 个问题（不止 2 个，避免被超出）
  ↓
面试结束当晚
  ↓
Step 6：复盘
  - 在面试档案里记：被问了什么 / 我答得怎样 / 哪些案例没用上 / 下次怎么改
```

## 5. 调用路径（按面试类型）

| 面试类型 | 优先翻 |
|---------|--------|
| HR 首轮电话（30min 内） | [[HR首轮电话脚本]] |
| 用人经理首面（行为题为主） | [[案例库]] + 当场面试档案 |
| 跨部门面 / 业务面（数据/方案问得深） | 案例库 BPCE-05/06、NCR-01 等深度案例 |
| 高层终面（战略 / why us / 5 年规划） | HR 脚本 + 案例库领导力故事 |
