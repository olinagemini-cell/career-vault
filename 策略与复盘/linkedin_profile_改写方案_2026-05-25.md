## 二、Headline 改写

### 2.1 现状评估（需要你确认）

请先打开你现在的 LinkedIn，把 Headline 原文贴出来对比。如果是这种类型：
- "Senior PM | Open to opportunities | Driving transformation" → ❌ 关键词稀薄
- "Project Manager at BPCE" → ❌ 默认值，浪费搜索字段

下面是按你的目标赛道设计的 3 个版本。

### 2.2 三个候选版本（120 字符上限）

#### 🅐 乙方 IT Delivery 主攻版（推荐下周用）

```
Program / Delivery Manager · 14 yrs Financial Services IT · BPCE · $50M+ APAC Portfolio · Cross-border Delivery · Open to Work
```

字符：≈119
**搜索命中词**：Program Manager / Delivery Manager / Financial Services / BPCE / APAC Portfolio / Cross-border / Open to Work

#### 🅑 外资保险/银行 BRM 偏重版（长期赛道用）

```
Senior IT PM · Trusted Business Partner to COO · 14 yrs in Banking & Leasing · BPCE · Cross-border Digital Transformation
```

字符：≈118
**搜索命中词**：Senior IT PM / Business Partner / COO / Banking / Leasing / BPCE / Digital Transformation

#### 🅒 双赛道兼顾版（如果你不想换来换去）

```
Program / Delivery Manager · 14 yrs IT Delivery in Banking & Leasing · BPCE · Cross-border APAC · RFP/QBR · Open to Work
```

字符：≈117
**搜索命中词**：Program Manager / Delivery Manager / Banking / Leasing / BPCE / Cross-border / APAC / RFP / QBR

### 2.3 Headline 关键词逻辑

| 必须出现 | 强烈建议 | 避免 |
|---------|---------|------|
| Program Manager / Delivery Manager（直接对 title） | 14 yrs + 金融/银行（含金量化年限） | "Driving X" / "Passionate about X"（动作词，没搜索价值） |
| BPCE（知名 logo） | $50M / APAC（量化 + 地理） | "Open to opportunities"（→ 改用 LinkedIn 自带的 Open to Work badge） |
| Open to Work（recruiter filter 会用） | Cross-border（差异化关键词） | "AI" / "Innovation"（太宽泛） |

## 三、About 段改写

### 3.1 开场前 2 行（关键）

**这两行要跟简历 Summary 完全一致**——recruiter accept 你之后会比对 profile vs 简历，对得上才有可信度。

```
Program / Delivery Manager with 14 years of IT delivery in financial 
services (6 yrs fintech + 4 yrs equipment-leasing) and MNC cross-border 
environments. Managed $50M+ delivery portfolios across Greater China, 
leading 15+ parallel programs spanning major KA engagements, RFP responses, 
and QBR governance.
```

### 3.2 完整 About 段（≈180 words，适合 LinkedIn）

```
Program / Delivery Manager with 14 years of IT delivery in financial 
services (6 yrs fintech + 4 yrs equipment-leasing) and MNC cross-border 
environments. Managed $50M+ delivery portfolios across Greater China, 
leading 15+ parallel programs spanning major KA engagements, RFP responses, 
and QBR governance.

What I bring to the table:

• Dual perspective — 6 yrs vendor-side delivery leadership at NCR + 
  in-house program ownership at BPCE (French banking group), reporting 
  to the COO

• Track record — 3 consecutive years of #1 APAC portfolio ROI, 20+ 
  production releases with zero major incidents, 3-year clean financial 
  audit period

• Multi-country execution — coordinating delivery across China, Europe 
  and APAC under cost-shared governance; bilingual CN/EN

• Strong on RFP / QBR / SLA governance, vendor coordination, and 
  multi-country stakeholder management

Currently open to senior Delivery / Program / Engagement Manager roles 
in Shanghai — consulting (Accenture / Capgemini / TCS / Infosys type 
firms), MNC in-house IT, or financial services technology.

Feel free to reach out: olina11151@outlook.com
```

### 3.3 About 段几个关键设计点

| 设计点 | 为什么这样 |
|-------|----------|
| 第一句**完全照搬简历 Summary** | profile 与简历对齐 = 可信度 |
| 三个 bullet 都带量化 | senior PM 没有数字 = 没有 credibility |
| 明确写"open to xxx roles in Shanghai" | 让 recruiter 在 30 秒内知道你要什么、在哪里 |
| 末尾留邮箱 | LinkedIn message 有时被埋，邮箱兜底 |
| **不放 AI 工具名** | 保持简历一致的诚信边界 |

## 五、Skills 排序（recruiter filter 会用）

LinkedIn 允许 Top 3 Skills 置顶，recruiter 在 filter 时可以按 Skills 筛人。**Top 3 必须是 recruiter 真正搜的词**。

### 推荐 Top 3（按目标赛道）

| 排位 | Skill |
|------|-------|
| 1 | **Program Management** |
| 2 | **IT Delivery** |
| 3 | **Portfolio Management** |

### 紧随其后的 7 个（也很重要）

- Project Management
- Vendor Management
- Stakeholder Management
- Cross-functional Team Leadership
- PMO
- Digital Transformation
- Financial Services

### 不建议放进前 10 的

- ❌ AI / Machine Learning（除非投 AI 岗，否则稀释信号）
- ❌ Agile Methodologies（太基础，所有 PM 都有）
- ❌ Microsoft Office（默认能力，浪费 slot）

## 六、Open to Work 设置

你说已经开了，但要确认 3 件事：

| 检查项 | 应该怎么设 |
|--------|----------|
| 可见性 | **"Recruiters only"**（不是 "All LinkedIn members"，避免现公司同事看到） |
| Job titles | 至少填 5 个：Program Manager / Delivery Manager / Senior PM / Engagement Manager / IT Project Manager |
| Locations | Shanghai + Remote |
| Job types | Full-time, Permanent |
| Start date | "Immediately" 或 "Flexible"（不要写 "Not currently looking"） |

## 七、改写后效果验证

改完之后，用下面方法自检：

### 方法 1：自己搜自己

在 LinkedIn 搜索栏输入下面任一关键词，看你的 profile 是否在前 50 个结果：
- `Program Manager Shanghai financial services`
- `Delivery Manager Shanghai BPCE`
- `IT Project Manager Shanghai APAC`

如果搜不到，说明关键词密度还不够。

### 方法 2：让朋友扫一眼

找一个不了解你工作的朋友（最好懂英语的），让他看你的 profile **5 秒钟**，然后问：
- 这个人做什么的？→ 应该答出 "PM / Delivery Manager"
- 多少年经验？→ 应该看到 "14 yrs" 或 "10+ yrs"
- 哪个行业？→ 应该看到 "Banking / Financial Services"

如果三个问题答不出，profile 还要再压缩。

## 八、不要做的事

- ❌ **不要主动告知现公司你在找工作**——Open to Work 设 "Recruiters only" 已经够了
- ❌ **不要为了对齐简历就一字不差地复制**——简历是给 ATS 看的，profile 是给人 + 算法看的，调性差异要保留
- ❌ **不要写 "Driving transformation" / "Passionate about innovation"** 这类抽象词——没有搜索价值，HR 视而不见
- ❌ **不要在 About 写 AI 工具名**——跟简历一致的诚信边界
- ❌ **不要发求职 post**（"I'm looking for a new opportunity..."）——senior PM 这种 post 反而显得 desperate
