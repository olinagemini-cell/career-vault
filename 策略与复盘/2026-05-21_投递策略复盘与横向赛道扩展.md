## 2. 横向赛道分级（基于 skill-modules 的真实素材匹配）

### 2.1 用户素材的稀缺度排序（独立于赛道）

| 素材 | 稀缺度 | 用在哪个赛道 |
|------|-------|------------|
| 直接汇报 COO 的高管接口经验（BPCE 3 年） | ★★★ | Chief of Staff、IT BRM、Strategy Ops |
| P&L + cash-out 双维度预算治理 | ★★★ | Finance Systems PM、IT Director、IT BRM |
| 跨矩阵无授权影响力（HQ 资源争取） | ★★★ | 全部 |
| PIPL+GDPR 双法域 3 年零事故 | ★★ | Data Governance、合规 PM |
| $50M 组合 / #1 APAC ROI 3 年 | ★★ | Senior PgM、Portfolio Manager |
| 会计本科 + 国际商务硕士 | ★★（被严重低估） | Finance Systems PM、Finance Transformation |
| 飞书+Claude Code 低代码工具熟练度 | ★★ | 数字化转型、AI 相关 |

### 2.2 Tier 1：直接迁移，简历几乎不改

#### 赛道 A — Chief of Staff / COO Office / 战略办公室
- **使用模块**：BRM + 商业论证 + 投资组合 + 跨境
- **搜索关键词**：`Chief of Staff`、`Strategy & Operations Manager`、`Business Operations Lead`、`COO Office Manager`、`总经理办公室`、`战略运营`
- **目标公司**：MNC 中国总部、PE/VC portfolio、外资银行 Strategy Office、保险 COO Office

#### 赛道 B — Senior Program Manager / Portfolio Manager（非 IT 纯交付）
- **使用模块**：投资组合 + 商业论证 + 变革管理
- **搜索关键词**：`Strategic Initiatives Manager`、`Transformation PMO`、`Enterprise PMO Lead`、`Business Transformation Manager`
- **目标公司**：保险战略 PMO、Big Pharma Operations PMO、Bank Strategy Office

#### 赛道 C — IT BRM / IT Business Partner（已在做，扩面）
- **使用模块**：BRM + 商业论证 + 投资组合 + 供应商管理
- **当前盲区**：外资保险、外资银行、Big 4 Advisory
- **优先目标**：BNP Paribas（法资同业故事最强）、AXA、AIA、Allianz、Manulife、SocGen、DB、Standard Chartered

### 2.3 Tier 2：素材 80% 够，需调整叙事

#### 赛道 D — Vendor Management / IT Sourcing / Strategic Sourcing
- **使用模块**：供应商管理（NCR 重仓）+ 商业论证 + 双维度预算
- **诚信边界**：BPCE 段不碰
- **搜索关键词**：`Vendor Manager`、`IT Sourcing Manager`、`Strategic Sourcing`、`Procurement Lead - IT Services`

#### 赛道 E — Finance Systems PM / Finance Transformation PM ⭐ 重点高潜
- **为什么值得专门做**：会计本科 + 国际商务硕士 + 14 年 IT PM + P&L/cash-out 双维度 = 这个赛道几乎为该 profile 定制
- **使用模块**：BA + ERP/CRM + 商业论证 + 跨境
- **搜索关键词**：`Finance Systems Manager`、`Finance Transformation PM`、`SAP S/4HANA PM`、`FP&A Systems Lead`、`财务系统PM`
- **目标公司**：Big Pharma Finance Transformation 团队、Big 4 Advisory Finance Consulting、消费品 MNC（联合利华/雀巢/欧莱雅）Finance IT
- **缺口**：当前简历库无该方向定向版，需新建模板

#### 赛道 F — Management Consulting Senior（Big 4 Advisory）
- **使用模块**：BRM + 商业论证 + 跨境 + 变革管理
- **定位**：Senior Consultant / Manager 级，不是 Junior
- **目标公司**：PwC Advisory、Deloitte Consulting、EY Advisory、KPMG Advisory、Capgemini、NTT Data、Infosys Consulting、Accenture Strategy

#### 赛道 G — Compliance / Data Governance PM
- **使用模块**：PIPL+GDPR + 跨境 + 投资组合
- **搜索关键词**：`Data Governance Manager`、`Privacy Program Manager`、`Compliance Operations Manager`
- **目标公司**：所有跨境数据流的 MNC（互联网/科技/医药/金融）

### 2.4 Tier 3：素材有但需重新叙事（性价比一般）

| 赛道 | 备注 |
|------|------|
| B2B Product Manager（Enterprise SaaS） | 要换 product mindset 叙事，不如 T1-T2 |
| Pre-Sales / Solution Consultant（厂商侧） | 与甲方 PMO 路径有落差感 |

### 2.5 不建议（跟素材脱节）

- 互联网 B2C 产品经理
- 软件研发管理
- 纯运营 / 纯销售
- 招聘 / 培训类
