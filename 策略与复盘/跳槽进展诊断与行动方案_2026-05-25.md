# 跳槽进展诊断与行动方案 — 2026-05-25

> 用户：Olina Liu（14 年 PM，6 年 fintech + 4 年金融租赁，现职 BPCE ES）
> 触发：投递 2-3 周 / 30-40 家 / 仅 1 个 assessment 反馈
> 输出：诊断 + 简历骨架（A）+ 猎头 outreach 包（B）

---

## 一、漏斗诊断

### 1.1 数字本身

```
2-3 周  ×  30-40 家  =  1 个 assessment 反馈
回复率 ≈ 2.5-3%
```

Senior IT PM 外企市场 cold apply 的 benchmark 是 5-10%。这个数字本身**不算崩盘**，但属于"系统按预期工作"——问题不是简历，是漏斗。

### 1.2 真正的问题：渠道结构致命单一

| 入口 | 你的占比 | Senior PM 市场实际占比 |
|------|---------|----------------------|
| 猎头 / Recruiter 主动联系 | **0%** | 30-40% |
| 内推（前同事/朋友） | **0%** | 25-35% |
| Hiring Manager LinkedIn 主动接触 | **0%** | 15-20% |
| Cold apply（LinkedIn Easy Apply + 官网） | **100%** | 10-15% |

**Open to Work 开关只是"被动可见"，不是"主动出击"**——你只占了那 10-15% 的池子。

### 1.3 其他三个次要问题

**问题 2：岗位定位过度发散**

跟踪表横跨：AI Lab、银行、保险、航运、药企、汽车 IT、咨询、消费品、制造、金融科技、乙方 IT…
**每个赛道只投 2-3 家，没有形成单赛道密度**。HR 看到的是"一个什么都投的人"，不是"铁了心要进某赛道的人"。

**问题 3：通用简历 Summary 不抓人**

现 Summary 开场词："Seasoned Digital Transformation Program Manager specializing in cross-border IT delivery..."

- 95 词长度，HR 6 秒扫读最多看清前 2 行
- 前 2 行没有出现你最稀缺的 3 个标签：**金融行业、BPCE 法资银行、向 COO 汇报**
- "Seasoned Digital Transformation PM"——title 满大街

**问题 4：14 年金融纵深被埋**

你的自我介绍是"6 年 fintech + 4 年金融租赁"，但通用简历里：
- 只看到 BPCE 在最上面
- NCR 是 "$50M portfolio" 但不知道是金融
- **贯穿 14 年的金融行业纵深完全看不出来**

你最大的差异化标签（金融纵深 + 双视角）被埋了。

## 七、不建议做的事

- ❌ **继续 cold apply 新公司** — 同样的简历投更多家不会改变转化率
- ❌ **同时改通用版去讨好 4 个赛道** — 会越改越钝；本次乙方版是独立骨架，不动通用版
- ❌ **connect 时附简历** — accept 之后再发，避免给"我急着找工作"信号
- ❌ **同一家公司同时 connect 5 个 recruiter** — 内部会知道，分 2 个就够
- ❌ **群发 connect message** — 不改 first name 会被 LinkedIn 标记 + 被 recruiter 秒删
- ❌ **第一封信谈薪资期望** — 锁价过早，要留到 intro call 之后

## 八、复盘节点

| 日期 | 检查点 | 决策 |
|------|--------|------|
| 6/8（2 周后） | accept 率 / 回复数 / call 数 | 是否换 recruiter 群体 / 调 message 版本 |
| 6/22（4 周后） | intro call → 推岗位 转化 | 是否继续乙方 IT / 切换 / 并行其他赛道 |
| 7/6（6 周后） | 实际面试转化 | 简历是否需要二次调整 |

**节奏失效信号**：
- accept 率 < 30% → 换 connect message 版本（试 🅑 或 🅒）
- 简历发出 7 天 0 回复 → 这波 recruiter 不在 active loading 期，留到 follow-up
- intro call ≥ 3 个/周 → 渠道生效，进入正循环
